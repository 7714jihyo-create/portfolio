# 404 General Hospital (종합병원 404)

### 1. StartScene (메인 로비)
* **시작하기 버튼:** 클릭 시 `GameScene`으로 전환
* **게임방법 버튼:** 클릭 시 플레이 방법 설명 팝업 출력
  * ⚙️ *Fix Required:* 닫기 버튼 동작 미구현 (수정 예정)

---

### 2. GameScene (메인 플레이)
* **차트 오브젝트:** 클릭 시 환자 정보 모니터링
* **모니터 오브젝트:** 클릭 시 진단서 작성 및 제출 UI 활성화
  * ⚙️ *Fix Required:* 누끼(배경 투명화) 작업 필요
  * ⚙️ *Feature Needed:* 닫기 버튼 및 타이머 시스템 구현 필요
* **LLM API 연동:** Gemini API 통신 구현 완료
* **진행 제어:** API 응답 수신 후 30초 대기 타이머 카운트다운 완료 시 '다음으로' 버튼 활성화
  * ⚙️ *Feature Needed:* 종족에 따른 환자 캐릭터 스폰 시스템 구현 필요

---

### 3. WaitingScene (라운드 결과)
* **AI 서사 연출:** 유저의 진단서에 따른 AI의 진후 시나리오 및 점수 출력
  * ⚙️ *Prompt Tuning Needed:* 환자 증상 참고 및 점수 출력 위한 프롬프트 업데이트 필요

---

### 4. ResultScene (최종 결과)
* **씬 전환:** `WaitingScene` 3회 진행 후 자동으로 `ResultScene` 전환
* **최종 점수:** 각 라운드별 점수 누적 합계 출력
* **로비 이동:** '로비로 돌아가기' 버튼 클릭 시 `StartScene`으로 전환
